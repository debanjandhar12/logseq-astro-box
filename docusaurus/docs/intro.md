# Logseq AstroBox

Logseq AstroBox is a harness for Logseq with superpowers. It provides a chat UI,
skills, and commands. It runs in a sandboxed environment by default, and every write
goes through a reversible transaction tracker, so changes can be reviewed and
reverted before they are committed.
